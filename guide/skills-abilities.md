# 战技 & 被动

## 主动战技

简称**战技**。释放战技会消耗**爆发能量**。

| 属性 | 说明 |
|---|---|
| 初始状态 | 无，需通过学习解锁 |
| 学习后等级 | 1 级 |
| 最高等级 | 6 级 |
| 升级所需等级 | 12/24/36/48/60 |
| 吟唱 | ❌ 不需要，可以直接发动技能效果 |

## 被动战技

简称**被动**。被动会**随时判断**其所需条件是否成立，并使效果生效。

| 属性 | 说明 |
|---|---|
| 初始状态 | 可能需要通过学习解锁 |
| 学习后等级 | 1 级 |
| 升级 | 通常被动技能没有升级选项 |
| 触发方式 | 随时判断条件是否成立并生效 |

## 战斗天赋

根据角色的定位（核心、先锋、近卫、支援、治疗），角色可以学习得到与之定位相应的**战斗天赋**。这些战斗天赋**属于被动战技**。

| 定位 | 可获得对应天赋 |
|---|---|
| 核心 / 先锋 / 近卫 / 支援 / 治疗 | 各自定位的战斗天赋 |

- 当角色具有**多个定位**时，允许角色学习多个战斗天赋
- 但只能选择其中 **1 个**战斗天赋生效
