# 决策点

决策点表示角色在回合内允许的**操作数量**。

> 决策点由游戏平衡常数设置，与角色能力值无关。每个角色的决策点是独立的。

## 决策点配额

默认情况下，回合内各类行动各限一次，称为"配额"：

| 行动 | 默认配额 |
|---|---|
| 普通攻击 | 1 |
| 战技 | 1 |
| 爆发技 | 1 |
| 魔法 | 1 |
| 物品 | 1 |
| 协同确认 | 不限次数，仍受决策点预算限制 |

被动技能和特效可以操作决策点及其配额，赋予动态策略性。

::: info 临时全能配额
临时全能配额叠加到普攻、战技、爆发技、物品与其他动作配额，魔法配额不接受临时全能加成。回合结束只清理回合角色本人的临时配额。
:::

## 初始化与补充

| 规则 | 数值 |
|---|---|
| 入队时初始决策点及上限 | 1 |
| 首次非吟唱回合的上限 | 2（回合入口提升 1） |
| 回合开始时补充 | 上限的一半（向下取整，至少 1） |
| 每次非吟唱回合开始 | 上限 +1（最多 7） |
| 完全行动不能/行动受限 | 仅补充上限的 1/4（向下取整，至少 1） |

## 使用消耗

| 行动 | 消耗 |
|---|---|
| 普通攻击 | 1 决策点 |
| 战技 / 魔法 | 2 决策点 |
| 物品 | 1 决策点 |
| 回合内爆发技 | 2 决策点 |
| 回合外爆发技 | 3 决策点 |
| 协同确认 | 协调方 1 决策点；协作方另付自身动作成本 |

## 硬直时间（多次行动）

当回合内行动次数 > 1 时：

```
回合结束时硬直时间 = 最长一次行动的硬直时间 + 本回合已使用的决策点数量
```

没有多次计数行动时，按本回合动作硬直的最大值结算。

## 特殊情况

- 回合内吟唱魔法 → 直接结束回合
- 预释放爆发技的结算也沿用主循环；保留的计数达到多行动条件时仍使用正常聚合规则
- 先行动再吟唱 → 硬直时间累计到吟唱结算的回合

普通魔法与预释放爆发技的结算回合不补点，保留发起回合的计数。协同魔法结算同样不补点，但会清空协作方上一正常回合已消费的计数，防止把旧动作重复加入本次结算。

协作动作只消耗 B 的当前 DP 和对应配额，不增加 B 上一正常回合的行动次数或已用 DP 统计。结算失败计默认 3 的失败尝试硬直，不额外扣 DP 或增加行动次数；可以在剩余预算与配额内重新决策。参见[协同行动](/guide/chain-action)和[魔法](/guide/skills-magic)。
