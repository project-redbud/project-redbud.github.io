能力值详解 ​

角色各方面的能力值，包括：生命值、魔法值、爆发能量、行动速度（行动系数）、攻击力、物理护甲（物理伤害减免）、魔法抗性、加速系数、闪避率、暴击率、暴击伤害、物理穿透、魔法穿透、冷却缩减、生命回复、魔法回复。

基础能力值与额外能力值 ​

  • 基础能力值：角色基于初始属性、核心属性、等级等因素计算的
  • 额外能力值：通过装备、技能等方式获得的属性加成

HP / MP / STR / AGI / INT / ATK / DEF 的 ExPercentage 乘对应 Base；其他能力使用各自的字段与公式，不共用这组百分比槽位。

运算规则 ​

能力值类型是否具备基础值加成方式
最大生命值 / 最大魔法值 / 力量 / 敏捷 / 智力 / 攻击力 / 物理护甲✅ Base*固定点数 Ex2 与 Base × Ex*Percentage；战斗属性另含额外核心属性来源
爆发能量上限由 MaxEP 配置当前 EP 可读写，不使用 ExEP2 或 ExEPPercentage
行动速度初始速度与敏捷贡献加上 ExSPD，下限 0，不使用 ExSPDPercentage
魔法抗性 / 穿透按分桶或对应字段设置魔抗仅限制上界 1；穿透限制在 0 至 1
加速系数 / 冷却缩减 / 暴击 / 闪避默认值、核心属性贡献与额外项按各自公式相加和钳制，不自动套用七组属性的百分比模型
生命回复 / 魔法回复初始值、力量 / 智力贡献及额外值相加后下限 0
攻击距离 / 移动距离✅ 分基础/额外相加后下限 1；战棋地图使用有效距离

初始能力值 ​

定义：Initial* 是初始配置项；1 级最终能力还包含核心属性与额外加成，不能直接把 Initial* 当作最终值。

这个很重要——具备初始能力值的能力值类型，其数值可能影响每次提升等级时，一同提升的能力值。

角色存在以下初始能力值：

初始能力值影响
初始生命值影响基础最大生命值成长
初始魔法值影响基础最大魔法值成长
初始行动速度直接决定开局行动系数
初始攻击力影响基础攻击力成长
初始物理护甲直接参与物理伤害减免
初始生命回复生命回复的初始加算项
初始魔法回复魔法回复的初始加算项

HP / MP / STR / AGI / INT / ATK / DEF 七组属性的固定点数写入 Ex*2，比例写入 Ex*Percentage；Ex*3 是基础值乘以比例，Ex* 汇总全部额外来源。公式采用默认平衡常数，实际以实例配置为准。当前 HP / MP 可读写，提高上限不会自动补满。

最大生命值 ​

角色的基础最大生命值基于以下公式计算：

基础最大生命值 = 初始生命值 + (等级 - 1) * (17 + 0.68 * 初始生命值) + 基础力量 * 13
额外生命值 = 额外力量聚合 * 13 + 额外生命固定点数 + 基础最大生命值 * 额外生命比例
最大生命值 = Max(1, 基础最大生命值 + 额外生命值)

最大魔法值 ​

角色的基础最大魔法值基于以下公式计算：

基础最大魔法值 = 初始魔法值 + (等级 - 1) * (1.5 + 0.14 * 初始魔法值) + 基础智力 * 8
额外魔法值 = 额外智力聚合 * 8 + 额外魔法固定点数 + 基础最大魔法值 * 额外魔法比例
最大魔法值 = Max(1, 基础最大魔法值 + 额外魔法值)

速度按初始值、敏捷和 ExSPD 相加，下限为 0；能量上限来自 MaxEP。它们不使用七组属性的 Ex2 / ExPercentage 槽位。暴击率、闪避率与穿透限制在 0 至 1，暴击伤害倍率不统一钳制。

爆发能量 ​

角色释放战技和爆发技所需的能力值。

  • 爆发能量最大值为 200 点
  • 角色造成、受到伤害都会获得少量的爆发能量
  • 我们统一能量值的术语为获得，而不是回复

行动速度 ​

角色的行动速度在战斗开局时起关键作用。在战斗过程中，行动速度会按公式转化为角色的行动系数，行动系数用于减少硬直时间。

行动速度 = Max(0, 初始速度 + 敏捷 * 0.65 + ExSPD)
行动系数 = Clamp(行动速度 / 1500 + ExActionCoefficient, 0, 0.9)

示例

额外行动系数为 0 时，290 速度 → 行动系数显示为 290 / 1500 * 100% = 19.33% 当硬直时间为 5 时 → 实际硬直时间 = 5 * (1 - 19.33%) = 4.03

默认 SPDUpperLimit = 1500 且额外行动系数为 0 时，速度 1350 达到 90% 系数上限；速度本身并未限制为 1350。详见 行动顺序表。

攻击力 ​

角色的基础攻击力由初始攻击力及其成长和基础核心属性相加而成：

基础攻击力 = 初始攻击力 + (等级 - 1) * (0.95 + 0.045 * 初始攻击力) + 基础核心属性
总攻击力 = 基础攻击力 + 额外攻击力加成

物理护甲和物理穿透 ​

在物理伤害计算中，物理护甲最终会转换成物理伤害减免参与伤害计算：

物理伤害减免 = 物理护甲 /（物理护甲 + 240）* 100%（保留两位小数）

物理穿透用于削减目标角色的物理护甲。例如角色 1 的物理穿透为 30%，角色 2 的物理护甲为 60：

(1 - 0.3) * 60 = 42（角色 2 的物理护甲最终取 42）

详见 伤害计算 - 物理伤害。

魔法抗性和魔法穿透 ​

魔法抗性将直接参与到伤害计算中（与物理护甲 → 物理伤害减免的转换同理），魔法穿透直接作用于魔法抗性。因没有魔法护甲，所以魔法穿透将直接作用于魔法抗性。

特别地，魔法伤害具有属性（星痕、光、影、元素等），角色的属性或技能的伤害属性会应用不同的魔法抗性，但魔法穿透为共用属性。详见 伤害计算 - 魔法伤害。

加速系数 ​

这涉及魔法理论。如果角色想要释放魔法技能，角色必须先经过一段时间的吟唱（或说施法、蓄力或引导），在本游戏的系统中标准称呼为吟唱时间。

  • 吟唱期间不进入常规行动选择，等待施法结算或被打断
  • 满足预释放条件时，可以通过预释放爆发技覆盖原吟唱；原施法及顺延奖励会被清理，按预释放规则插队

对行动顺序表作一些补充：

  1. 当角色在回合中确定吟唱魔法时，吟唱时间会替代硬直时间来使角色插入行动顺序表
  2. 但此时角色不适用行动系数来削减这个硬直时间，必须要用专门的加速系数来削减这个硬直时间

总而言之，加速系数是用来削减吟唱时间的。数值越大，角色将能更快释放出魔法。并且魔法技能也会有硬直时间，在角色释放魔法以后，要正常走行动顺序表中的硬直时间计算逻辑。

闪避率 ​

闪避率通常仅在成为普通攻击的目标时才有效。

这个指标将用于进行闪避检定，原理为投掷一个 100 以内的随机数，小于闪避率的值则视为角色闪避成功，将无法受到该普通攻击的伤害。

暴击率和暴击伤害 ​

这是两个令人兴奋的能力值。物理 / 魔法伤害在计算减伤后按选项进行暴击检定，检定原理与闪避类似，当暴击生效时，期望伤害将直接乘以暴击伤害。

  • 角色拥有 5% 初始暴击率
  • 角色拥有 125% 初始暴击伤害

暴击率与闪避率限制在 0 至 1，暴击伤害倍率不钳制；真实伤害走独立路径，不能据此推断其参与暴击。

冷却缩减 ​

冷却缩减可以减少所有主动技能（战技、魔法、爆发技）的冷却时间。

生命回复和魔法回复 ​

生命回复和魔法回复是在每次时间流逝时，根据流逝的单位时间，来计算此次回复的数值。

示例

某角色回合结束，时间流逝 1 秒，生命回复为 0.5，则此次回复的数值为 0.5 * 1 = 0.5。

生命回复和魔法回复均有初始值、额外值：

总生命回复 = Max(0, 初始生命回复 + 力量 × STRtoHRFactor + 额外生命回复)
总魔法回复 = Max(0, 初始魔法回复 + 智力 × INTtoMRFactor + 额外魔法回复)

生命偷取 ​

简称吸血，指角色在造成伤害时，从造成的伤害值中吸取一部分生命值，转化为生命回复治疗自身。

护盾值 ​

护盾是一种代替生命值结算伤害的机制，区分物理护盾和魔法护盾。护盾值通常由特效提供。

  • 角色在护盾生效期间受到伤害时，护盾值会被减少，用来抵挡伤害
  • 通常情况下，当护盾值减至 0 或者受到比护盾值更大的伤害时，护盾将被移除并且溢出伤害由角色生命值承担

特效可以有特殊设计，具体需要看特效的说明。

攻击距离和移动距离 ​

距离在战棋地图上是指两个角色之间的曼哈顿距离。

  • 基础攻击距离由武器提供
  • 基础移动距离则由角色的定位提供

攻击距离和移动距离只有在战棋地图上才会应用，仅接受加算。
