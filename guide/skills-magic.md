# 魔法

释放魔法会消耗**魔法值**。魔法通常来源于角色装备的**魔法卡包**，但部分角色也可能初始就自带魔法。

> 魔法卡包是魔法技能的主要来源，其标准实现见 [预制实体 - 魔法卡包](/guide/prefabricated-entities)。

## 魔法流程

```
行动回合 → 选择魔法 → 选择目标 → 开始吟唱 → 结束回合
   ↓
时间流逝 → 吟唱等待时间归零 → 轮到施法者的结算回合
   ↓
释放成功 → 结算动作硬直与奖励 → 等待下一次行动
释放失败 → 计失败尝试硬直 → 按剩余预算和状态重新决策
```

开始吟唱时检查魔法值，结算回合重新检查并在释放时扣除。吟唱结算是独立的正常回合，会触发回合开始/结束、发放与回收奖励、增加行动回合计数。处于吟唱态时直接处理释放，不选择新的主动动作；释放失败或提前被打断后可以按正常规则继续决策。

结算回合不补充决策点。普通魔法保留发起回合的行动计数与已用配额，先行动再吟唱的硬直按正常多行动规则在释放回合聚合。协同魔法的预算和原队列位置规则见[协同行动](/guide/chain-action)。

## 吟唱终止

`r` 是剩余吟唱时间，`c` 是失败补偿，默认 3，可通过 `CastFailureHardnessTime` 配置。

| 情况 | 普通魔法的处理 |
|---|---|
| 在他人回合或时间流逝中被技能打断 | 取消施法，保持剩余等待时间 `r` |
| 在他人回合丢失全部目标 | 取消施法，等待时间为 `min(r,c)` |
| 没有角色正在行动时丢失全部目标 | 取消施法，保持 `r`，不应用补偿上限 |
| 在自己的结算回合资源不足、无有效目标或释放前被打断 | 失败尝试计 `c`，随后按剩余 DP、配额及控制状态继续决策 |
| 被预释放爆发技覆盖 | 取消原吟唱，按预释放规则设置位置，不另加失败补偿 |
| 死亡或移出队列 | 清施法状态与待释放技能，回收顺延奖励；重新加入或复活不恢复旧施法 |

只丢失部分目标时继续吟唱。非指向性魔法在保留目标格且允许空地施法时也可以继续。终止吟唱会立即重算控制状态，有控制效果的角色不会被强行变成可行动。

失败不返还已支付的决策点，也不额外扣失败费用；资源不足的释放尝试不扣 MP。失败尝试的 `c` 参与本回合硬直聚合，即使后续成功动作的硬直为 0 也不会抹掉该补偿；成功释放 0 硬直魔法本身不触发补偿。

所有施法终止都会回收已顺延的被动奖励。失败与打断记录归施法者，预释放覆盖或移出仅记录取消原因。

## 魔法瓶颈

部分魔法技能可能对角色的**智力**具有要求，我们称之为**魔法瓶颈**。

## 魔法效能

`魔法效能` 是一个表示魔法技能**实际施展效果被放大或缩小**的系数关系：以**魔法瓶颈为基准线**，角色智力减去魔法瓶颈的**差值的正负**决定了实际施展效果。

```
魔法效能 = 1.0 + (角色智力 - 魔法瓶颈) ÷ 魔法瓶颈
```

| 智力 vs 瓶颈 | 魔法效能 | 实际效果 |
|---|---|---|
| 智力 = 瓶颈 | 100% | 标准效果 |
| 智力 < 瓶颈 | < 100%（最低可降至 1%） | 效果被削弱 |
| 智力 > 瓶颈 | > 100%（至多可提升至 200%） | 效果获得增强 |
