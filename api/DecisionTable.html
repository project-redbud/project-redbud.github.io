决策表 API ​

配置与运行时模型位于 FunGame.Core.Model.DecisionTable，解析、构建、编译与加载入口位于 FunGame.Core.Api，代码策略接口位于 FunGame.Core.Interface。使用流程见 编写决策表。

配置模型 ​

类型属性
DecisionTableConfigSchemaVersion = 1、Id、Fallback = "defaultAI"、Rules
DecisionRuleConfigId、Enabled = true、Priority、Trigger = "beforeDecision"、Target?、When?、Action
TargetSelectorConfigRelation = "enemy"、Selector = "lowestHpRatio"、Bind = "target"
ConditionConfigType、All?、Any?、Not?、Target?、SkillId?、Operator = "atLeast"、Value、Parameters
ActionConfigType、SkillId?、ItemId?、Target?、Movement = "ifNeeded"、PositionPreference = "current"、BindPlan?、MaxRisk?、Parameters
DecisionDiagnostic记录类型 (string Path, string Message)，另有可初始化属性 Code = ""

SkillId / ItemId 为 long?，Value 为 double，MaxRisk 为 double?，扩展 Parameters 为 Dictionary<string, JsonElement>。完整字段值与条件语义见 配置指南。

解析与生成 ​

方法返回值 / 行为
DecisionTableParser.Parse(string json)DecisionTableConfig；格式错误抛出 JsonException
DecisionTableParser.TryParse(string json, out DecisionTableConfig? config, out IReadOnlyList<DecisionDiagnostic> diagnostics)bool；返回格式诊断，语义仍需 Validate
DecisionTableGenerator.GetJson(DecisionTableConfig config)string，camelCase JSON
DecisionTableGenerator.Save(DecisionTableConfig config, string path, bool overwrite = false)写入 UTF-8 文件，默认拒绝覆盖

Parser 拒绝未知字段，JSON 对象和数组最大深度为 64（包含扩展参数）；Generator 不代替 Compiler 校验配置。规则允许空列表但不可为 null，最多 256 条；条件根深度为 0，最多嵌套 16 级，all / any 每节点最多 64 个直接子条件。

构建与编译 ​

入口返回值 / 用途
DecisionTableBuilder.Create(string id)创建构建器
WithSchemaVersion(int version) / WithFallback(string mode)链式配置
AddRule(string id, Action<DecisionRuleBuilder> configure)构建时配置规则
Build(DecisionTableCompiler? compiler = null)经校验的配置快照，无效时抛出 ArgumentException
TryBuild(out DecisionTableConfig? config, out IReadOnlyList<DecisionDiagnostic> diagnostics, DecisionTableCompiler? compiler = null)bool，失败返回诊断
new DecisionTableCompiler(DecisionTableRegistry? registry = null, IEnumerable<long>? skills = null, IEnumerable<long>? items = null)可选扩展注册表与资源 ID 目录
Validate(DecisionTableConfig config)IReadOnlyList<DecisionDiagnostic>
Compile(DecisionTableConfig config)IDecisionPolicy，无效时抛出 ArgumentException；独立配置与注册表快照

DecisionRuleBuilder 提供 Priority、Enabled、On、Target、When、Then。辅助入口 Conditions.All/Any/Not/SelfHpRatio/TargetHpRatio/SkillAvailable/Compare、Targets.Self/Allies/Enemies、Actions.CastSkill/NormalAttack/UseItem/EndTurn 均返回配置对象；其他动作可直接构建 ActionConfig。

加载与绑定 ​

csharp
public sealed class DecisionTableLoader(DecisionTableCompiler? compiler = null)
方法返回值 / 用途
Register(DecisionTableConfig config)诊断列表；校验、编译、注册，不覆盖重复 ID
Register(string id, IDecisionPolicy policy)诊断列表；注册代码策略，不覆盖重复 ID
Load(string path)诊断列表；读取一个 JSON 文件并注册
Get(string id)IDecisionPolicy?，找不到时为 null
Bind(Character character)诊断列表；按 DecisionTableId 绑定，无 ID 解除，未知 ID 清除绑定并报错

配置策略可共享，角色 JSON 仅保存 ID。角色属性与生命周期见 Character。

Load 将文件读取阶段的 IOException、UnauthorizedAccessException、ArgumentException、NotSupportedException 转为路径诊断，JSON 格式错误由 Parser 返回；读取之外的编程异常继续抛出。重复注册返回 id 诊断，原策略保留。

代码策略与扩展 ​

csharp
public interface IDecisionPolicy
{
    DecisionEvaluationResult Evaluate(DecisionEvaluationContext context);
}

DecisionTableRegistry.RegisterCondition(string id, Func<DecisionEvaluationContext, ConditionConfig, DecisionPlan, bool> evaluate) 注册只读条件；RegisterAction(string id, Func<DecisionEvaluationContext, ActionConfig, TargetSelectorConfig?, IReadOnlyList<DecisionPlan>> plan) 注册只读规划器。扩展 ID 使用 module:name；重复注册抛出 ArgumentException，保留原扩展。

FunGame.Core.Controller.DecisionActionPlanner.Plan(DecisionEvaluationContext context, ActionConfig action, TargetSelectorConfig? selector) 返回 IReadOnlyList<DecisionPlan>，按当前局面生成合法候选。

求值上下文与结果 ​

类型 / 属性说明
DecisionEvaluationContext.Queue / Actor / Points必需初始化的 GamingQueue、Character、DecisionPoints
TurnOrigin / MoveGrids回合移动原点与候选位置
Skills / Items当前角色可用实例
Enemies / Allies / SelectableEnemies / SelectableAllies全部与可选角色集合
IsChainAction原地协同求值
AllowItem / AllowSkill / AllowAttack类别是否允许，默认 true
PositionBudget / CenterBudget / PlanBudget每动作位置 / 每位置中心 / 当前规划范围方案上限，默认 32 / 64 / 4096；策略与默认 AI 分阶段独立使用方案预算
RejectedRules本次行动尝试已失效的规则 ID 集合
RecentPositions近期实际离开的格子 ID
Metrics只读 DecisionMetrics 实例
DecisionPlan.Decision必需初始化的 AIDecision
Target / Center / SelectedGrids当前方案绑定目标、中心与覆盖格
TargetCount / Risk / MoveSteps合法角色数、近似风险、路径步数

上下文配置为 init 属性，评估期间不得修改引用的战斗对象。DecisionPlan.TargetCount 来自 Decision.Targets.Count。

DecisionEvaluationResult 是 (AIDecision? Decision, string? RuleId, IReadOnlyList<DecisionDiagnostic> Diagnostics)，Matched 表示 Decision != null；回退 endTurn 也属于有效决策，可没有命中规则 ID。指标见 AIController。

运行诊断 ​

DecisionDiagnostic.Path 定位配置路径或规则，Message 提供原因，Code 供程序分类；未分类的配置诊断使用空字符串。

Code含义
budget.exhausted没有剩余方案额度，跳过规划
budget.truncated位置、中心或方案搜索被预算截断
plan.unavailable当前局面无法生成可执行方案
condition.unmatched内置前置条件不成立，或已评估候选未满足条件
execution.rejected决策执行前重验失败
plan.invalid规划器未提供有效动作

condition.unmatched 与 budget.truncated 同时出现时，只能说明已搜索候选未命中。LastPlanningDiagnostics 汇总策略和回退阶段；不能仅凭未命中推断全局不存在合法行动。分配规则见 规则预算。
